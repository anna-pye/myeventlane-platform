## 1. Unescaped Output (|raw)

### CRITICAL — User-Controllable Content

**File:** node/node--event--full.html.twig

```twig
<div class="mel-info-row__value">{{ node.field_accessibility_contact.value|raw }}</div>
<div class="mel-info-row__value">{{ node.field_accessibility_entry.value|raw }}</div>
<div class="mel-info-row__value">{{ node.field_accessibility_parking.value|raw }}</div>
<div class="mel-info-row__value">{{ node.field_accessibility_directions.value|raw }}</div>
```

- **Risk:** Vendors can add HTML/JS via these fields. |raw outputs unescaped → XSS.
- **Classification:** **CRITICAL** — Replace with `|default('')` and appropriate format (e.g. `basic_html` filtered) or safe markup filter. Do not use |raw for user content unless explicitly sanitized.

### MEDIUM — Context-Dependent

**File:** commerce/commerce-checkout-completion.html.twig

```twig
{{ 'A confirmation email is on its way to <strong>@email</strong>...'|t({'@email': order_entity.getEmail()})|raw }}
{{ 'Your tickets have been sent... <strong>@order_number</strong>.'|t({'@order_number': order_entity.getOrderNumber()})|raw }}
{{ '...organiser at <a href="mailto:@email">@email</a>...'|t({'@email': vendor_email})|raw }}
```

- **Context:** @email and @order_number come from order/vendor data. t() escapes placeholders by default; |raw then unescapes.
- **Risk:** If order/vendor data is ever user-controlled in an unsafe way, XSS possible. Email and order number are usually constrained.
- **Classification:** Medium — Prefer rendering without |raw where placeholders are already escaped, or use #markup with Strict in render array.

**File:** mimemail-message.html.twig, mimemail-message--user--password-reset.html.twig

```twig
{{ body|raw }}
```

- **Context:** Email body from Mimemail/mail system. Body is typically generated by system, not arbitrary user input.
- **Classification:** Low — Email HTML requires raw for rendering. Ensure body source is trusted/sanitized.

### LOW — Safe Context

**File:** block/category-pie-chart.html.twig

```twig
labels: {{ labels|json_encode|raw }},
data: {{ counts|json_encode|raw }},
backgroundColor: {{ colors|json_encode|raw }},
```

- **Context:** json_encode produces JSON; |raw needed for JS. Labels/counts/colors from views/data layer.
- **Classification:** Low — Verify labels/colors are not user-controlled. If from taxonomy/views, generally safe.

**File:** html.html.twig

```twig
<head-placeholder token="{{ placeholder_token|raw }}">
```

- **Context:** placeholder_token from Drupal core; internal use.
- **Classification:** OK.
